# Mario Coach

Persönliche Web-App (PWA) für Training, Essen, Einkauf und Fortschritt. Nur für Mario.

- Inhalte der Woche: `data.js` (wird jede Woche aktualisiert)
- Übungsskizzen: `figures.js`
- Eigene Einträge und Fotos liegen nur im Browser auf dem Handy (localStorage / IndexedDB). Sicherung über „Fortschritt → Sicherung speichern“.
- Hosting: GitHub Pages, auf dem iPhone über Safari → Teilen → „Zum Home-Bildschirm“.
